# 网球回合剪辑

硬规则：一个回合（第一拍到球打死）放进一个片段，**不许剪碎**；捡球、走动、停顿、收手机都剪掉；原视频不动。

## 做法：只跑一条命令

```bash
python3 -I <本目录>/scripts/rally_cut.py auto <视频1> [视频2 ...]
```

它会自己完成：查画质 → 听击球声找回合 → 修掉片尾收手机的声音 → 剪成 mp4 → 核对每个成品时长。
成品放在第一个视频同目录的 `剪辑/`（已有旧成品会自动改名备份），并打印一份简短汇报和 Finder 链接。
1080p 60 帧要编码几分钟，放后台跑，跑完再看输出。

## 汇报

把脚本打印的汇报转述给用户即可：片段数、时长范围、Finder 链接，以及其中的 ⚠ 和「建议人眼看一下」。

- **不要**主动截图逐段看画面，也不要去别的目录找原片：判断已经由脚本按声音做完。
- 画质警告只转告用户，由用户决定要不要换原片。

## 用户有异议时

- 「把每次重新开球也单独分开」：把断开间隔改小，加 `--gap 4` 重跑。
- 「漏了 / 多了」：先 `--dry-run` 看切点，再按 `references/details.md` 调 `--k`、`--min-hits`。
- 用户指名某一段不对：读 `references/details.md` 的「看画面核对」，只对那一段出帧图。
